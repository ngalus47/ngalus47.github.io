# Nick Galus — Personal Website  

This repository contains the source code for my personal portfolio website, hosted at [nick-galus.github.io](https://nick-galus.github.io). The site serves as a central hub to showcase my engineering projects, coursework, research, and professional experience.  

---

## 🌐 Purpose  
The website is designed to provide recruiters, collaborators, and the general public with an overview of my work and interests. It highlights key projects, technical skills, and ongoing initiatives in computer engineering and related fields.  

---

## 🛠️ Tech Stack  
- **HTML5, CSS3, JavaScript** — for structure, styling, and interactivity  
- **GitHub Pages** — hosting platform  
- **Responsive Design** — mobile and desktop friendly  

---

## 📂 Features  
- **About Me** — introduction and background  
- **Projects** — curated list of engineering and personal projects  
- **Coursework** — academic highlights and applied learning  
- **Contact** — ways to connect with me (LinkedIn, GitHub, email)
